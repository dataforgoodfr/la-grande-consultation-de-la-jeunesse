### Prérequis

- Node v26 (il est recommandé d'utiliser (nvm)[https://www.nvmnode.com/] pour la gestion simplifiée des versions de Node sur votre machine)
- Git

### Installation

Dans le dossier `frontend/`, lancer la commande

```bash
npm install
```

### Lancer le projet en local

Pour lancer le projet il suffit d'exécuter la commande:

```bash
npm run dev
```
